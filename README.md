# Hose
A small tool designed to help you make a clean build for your Android app.

### Project selection
Pick a project from your portfolio.
It requires a .gradlew executable and a keystore file.
Hose will check if your git tree is clean in the meantime.

### Password entry
Enter your store password as well as your key password.
Hose will _hose_ down all artifacts which may interfere with release builds.
Submit your passwords and await for your freshly baked .apk!
